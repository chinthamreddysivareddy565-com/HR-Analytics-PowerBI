# HR Analytics Dashboard | Microsoft Power BI

## 📊 Project Overview

This project is an interactive HR Analytics Dashboard developed using Microsoft Power BI. The main objective of this project is to analyze employee data and generate meaningful insights into employee attrition, salary, age, experience, departments, job roles, gender, and job satisfaction.

## 🛠️ Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- Data Cleaning & Transformation
- Data Visualization

## 🔹 Data Cleaning & Transformation

Power Query was used to clean and transform the raw employee dataset.

- Removed duplicate records
- Cleaned and transformed the data
- Checked data consistency
- Prepared required columns for analysis
- Converted the data into a suitable format for visualization

## 🔹 DAX & KPI Calculations

Created DAX measures and formulas to calculate important HR metrics:

- Total Employees
- Active Employees
- Attrition Count
- Attrition Rate %
- Average Age
- Average Experience

DAX was mainly used for KPI calculations and percentage-based metrics such as Attrition Rate.

## 📈 Dashboard Features

The dashboard includes:

- Attrition by Department
- Attrition by Salary Slab
- Attrition by Job Role & Job Satisfaction
- Age Group Distribution
- Attrition by Gender
- Attrition Trend by Experience
- Department-wise Employee Count

## 🎯 Interactive Filters

The dashboard includes interactive slicers for:

- Department
- Age Group

These filters allow users to explore employee data dynamically and analyze different segments.

## 💡 Key Insights

The dashboard helps HR teams understand employee attrition patterns and explore how factors such as salary, age, experience, department, job role, and job satisfaction are related to employee turnover.
